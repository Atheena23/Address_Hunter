# Address Hunter — The Memory Case

A browser-only Computer Organization & Architecture microproject.

## Stack
- HTML
- CSS
- Vanilla JavaScript
- Local SVG assets
- Browser LocalStorage for progress

No backend, database, framework, build step, or server is required.

## Run
Open `index.html` in a modern browser.

## Gameplay
Explore the workshop -> open the computer -> identify the addressing mode -> find the effective memory location -> trace the data -> recover the memory chip -> unlock the next case.

## COA focus
The five cases cover:
1. Direct addressing
2. Indirect addressing
3. Register addressing
4. Indexed addressing
5. Register-indirect addressing

The interactions are deliberately click-based so the game is easy to play on desktop and mobile.

## Notes
All visual backgrounds and UI assets in this starter project are local SVG illustrations created for the project. They can be replaced later with your own licensed artwork without changing the game logic.
